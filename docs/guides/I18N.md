# i18n — Internationalization Guide

This fork ships **English only**, in the dashboard and in the CLI. The documentation is
English-only too. Upstream OmniRoute translates into many languages; the fork removed those
catalogs and their translation tooling ([`docs/ops/FORK_IDENTITY.md`](../ops/FORK_IDENTITY.md)).

The next-intl runtime stays, so components keep calling `t("key")` and a new string still goes
into a catalog instead of the JSX.

## Where the strings live

| File                                      | What it holds                                                    |
| ----------------------------------------- | ---------------------------------------------------------------- |
| `config/i18n.json`                        | The locale list: `en` only. `src/i18n/config.ts` reads it.       |
| `src/i18n/messages/en.json`               | Every dashboard string, by namespace.                            |
| `bin/cli/locales/en.json`                 | Every CLI string (`bin/cli/i18n.mjs`).                           |
| `src/i18n/global-error-messages/en.json`  | The error-boundary strings, generated from `en.json`.            |
| `src/i18n/route-handler-messages.json`    | The few strings route handlers render, generated from `en.json`. |
| `src/i18n/routeNamespaces.generated.json` | Which namespaces each route section loads.                       |

## Adding or changing a string

1. Add the key to `src/i18n/messages/en.json` (dashboard) or `bin/cli/locales/en.json` (CLI).
2. Use it through `useTranslations` / `getTranslations` (dashboard) or `t()` from
   `bin/cli/i18n.mjs` (CLI).
3. If the key is under `publicSystem.globalError` or a route handler renders it, regenerate the
   compact catalogs: `node scripts/i18n/generate-global-error-messages.mjs`.
4. If a route section starts using a new namespace, regenerate the map:
   `pnpm run gen:i18n-routes`.

## Checks

- `pnpm run check:ui-icu` compiles every message of `en.json` with the ICU parser next-intl
  uses. CI runs it in the `i18n UI Coverage` job.
- `pnpm run check:cli-i18n` fails when a CLI command calls `t()` with a key `en.json` lacks.

## Upstream merges

An upstream release brings new locale catalogs, translation scripts and per-locale tests. Delete
them in the merge, and keep only the English half of any test that checks several languages.
